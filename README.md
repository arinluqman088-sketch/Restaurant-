# Restaurant POS Cloud Sync 🍽️

Login:
- Cashier/Admin: admin / 1234
- Captain iPad: any username / 1111
- Kitchen Screen: any username / 2222

Features:
- Realtime Firestore sync
- Captain can take orders on iPad
- Cashier sees orders instantly
- Kitchen Display
- Menu / Stock
- Checkout + Receipt
- Customers
- Expenses
- Reports

Before using:
1. Enable Firestore Database in Firebase Console.
2. For testing, paste rules from FIRESTORE_RULES_TEST.txt.
3. Upload files to GitHub Pages.
